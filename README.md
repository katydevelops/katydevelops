These days, I'm focused on building hands-on experience in security operations, threat hunting, vulnerability management and cloud security.

A collection of hands-on security projects, investigations and technical write-ups built around real-world cybersecurity workflows.

Rather than stopping at theory, these projects focus on actually working through the process — investigating telemetry, identifying vulnerabilities, hardening systems, remediating findings and validating the results.

| Project | Description |
